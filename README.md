# Tamarind Table

A static, data-driven website for a fictional Hyderabadi restaurant in Tampa. Built for ISM 6225 Assignment 1 (Look and Feel).

**Live site:** https://harshxth.github.io/tamarind-table/

| Page | What it does |
| --- | --- |
| `index.html` | Restaurant overview, hours, and a menu explorer filtered by category, diet and search |
| `managemenu.html` | Mock CRUD: add, view, edit and delete menu items (saved in localStorage) |
| `analytics.html` | Chart.js dashboard: revenue trend, sales by category, top dishes, guests by day |
| `aboutus.html` | About the developer and how the site was built |

Plain HTML, CSS and JavaScript, no build step. About 60 KB of site code; Chart.js loads only on the analytics page. All data is sample data.
